# Saloon Reserve — Deploy Instructions

## Step 1: Supabase Setup
1. supabase.com pe jao → apna project kholo
2. Left menu mein "SQL Editor" click karo
3. SUPABASE_SETUP.sql ka poora content paste karo
4. "Run" dabao — tables ban jayenge

## Step 2: Vercel Deploy
1. vercel.com pe jao — free account banao (GitHub se login karo)
2. "Add New Project" click karo
3. "Upload" option select karo (ya GitHub se deploy karo)

## Step 3: GitHub se Deploy (Recommended)
1. github.com pe free account banao
2. New repository banao — "saloon-reserve" naam do
3. Yeh saare files upload karo
4. Vercel mein GitHub repo connect karo
5. Deploy! ✅

## URLs after deploy:
- Customer page: https://your-app.vercel.app/
- Owner dashboard: https://your-app.vercel.app/owner-dashboard-secret

## Owner Dashboard Settings:
- Apna WhatsApp number daalo
- Average wait time set karo
- QR code print karo aur salon mein lagao!
